# A KRT17/GATA6 hybrid state marks unique vulnerability to MYC in pancreatic cancer: Proteomics analysis

## Overview

This repository contains R scripts and input tables for the analysis of
level-3 proteomic abundance data from laser-capture microdissected (LCM)
pancreatic ductal adenocarcinoma (PDAC) samples.

Analyses compare four cell populations defined by GATA6 and KRT17 (K17)
expression:

| Label     | Cell Population                    |
|-----------|------------------------------------|
| GATA6     | GATA6+/K17− (Classical-like)       |
| K17       | GATA6−/K17+ (Basal-like)           |
| K17_GATA6 | GATA6+/K17+ (Hybrid/Dual-positive) |
| DUAL_NEG  | GATA6−/K17− (Double-negative)      |

These marker-defined groups are used for statistical comparisons and
do not independently establish temporal progression or lineage relationships.

## Input Data

### Protein Abundance Matrix

`input/stonybrook_pooled_lvl3_matrix.csv`

Contains protein abundance measurements from LCM-derived PDAC samples.

The `global.R` script processes the input matrix, constructs protein

`input/stonybrook_pooled_workorder.csv`

Contains sample annotations, including sample identifiers and GATA6/K17-defined
cell populations.

The `global.R` script standardizes group labels and aligns metadata with the
protein abundance matrix.

`input/msigdb_v2023.2.Hs_GMTs/`

- `c2.cgp.v2023.2.Hs.symbols.gmt`
- `h.all.v2023.2.Hs.symbols.gmt`

These files are used for gene-set enrichment analysis (GSEA) within the
differential abundance workflow.

## Running the Analyses

All scripts should be executed from the repository root directory.

Recommended execution order:

```r
source("scripts/limmas.R")

source("scripts/transitional_state.R")

source("scripts/unsupervised_lvl3.R")
```

The main scripts source `scripts/global.R`, which loads the protein abundance
matrix and metadata.

**Note:** The centroid projection analysis requires the GATA6 versus K17
limma output generated by `limmas.R`.

Therefore, the differential abundance analysis must be completed before running
`transitional_state.R`.

## Differential Protein Abundance Analysis

### Scripts

- `scripts/limmas.R`
- `scripts/limma_analysis_function.R`

Differential protein abundance analyses are performed using the limma
framework.

Pairwise comparisons are performed between the four GATA6/K17-defined cell
populations.

The comparisons include:

- DUAL_NEG vs GATA6
- DUAL_NEG vs K17_GATA6
- DUAL_NEG vs K17
- GATA6 vs K17_GATA6
- GATA6 vs K17
- K17_GATA6 vs K17

Additional comparisons evaluate individual populations against the remaining
populations.


### Outputs

Results are written to: `output/supervised_analysis/`

Individual comparisons are saved as:

```text
limma_<group1>_vs_<group2>.csv
```

The output tables contain differential abundance statistics,
including:

- Protein/gene identifiers
- logFC
- P.Value
- adj.P.Val

The file:

`output/supervised_analysis/summary_limma.csv`

summarizes significant protein counts across comparisons.

Nominal p-values and adjusted p-values are reported separately.

## Principal Component Centroid Projection Analysis

### Script

`scripts/transitional_state.R`

This analysis evaluates the relative positions of the GATA6/K17-defined cell
populations within proteomic principal component space.

### Protein Selection

Proteins are selected based on the differential abundance analysis comparing:

GATA6+/K17− versus GATA6−/K17+

Only proteins satisfying:

```r
P.Value < 0.01
```

are used in the PCA projection analysis.


### Centroid Calculation

For each cell population, the centroid is defined as the mean PCA coordinate
across samples belonging to that population.

The GATA6 centroid represents the Classical-like endpoint, while the K17
centroid represents the Basal-like endpoint.

The GATA6-to-K17 reference axis is defined as:

```text
axis = K17_centroid - GATA6_centroid
```

For a population being projected:

```text
h = transition_centroid - GATA6_centroid
```

### Projection Position (P)

The normalized scalar projection is calculated as:

```text
P = sum(h * axis) / sum(axis^2)
```

Interpretation:

- P = 0: Projection at the GATA6 centroid
- P = 1: Projection at the K17 centroid
- 0 < P < 1: Projection between the endpoints
- P > 1: Projection beyond the K17 endpoint
- P < 0: Projection beyond the GATA6 endpoint

The projected coordinate in PCA space is calculated as:

```r
proj_point <- vectors[[start]] + t_proj * axis
```

### Orthogonal Distance (O)

The Euclidean distance between the actual population centroid and its projected
position is calculated as:

```r
orth_dist <- sqrt(
  sum((vectors[[transition]] - proj_point)^2)
)
```

This distance is normalized by the length of the GATA6-to-K17 axis:

```r
axis_length <- sqrt(sum(axis^2))

O <- orth_dist / axis_length
```

The normalized orthogonal distance quantifies how far the centroid lies from
the reference axis relative to the distance between the two endpoints.

### Bootstrap Confidence Intervals

Uncertainty in centroid projection is assessed using 5,000 nonparametric
bootstrap iterations.

Within each iteration:

1. Samples are resampled with replacement within each cell population.
2. Group centroids are recalculated.
3. The GATA6-to-K17 reference axis is recalculated.
4. The projection position and orthogonal distance are recalculated.

The 95% confidence interval for the projection position is determined using the
2.5th and 97.5th percentiles of the bootstrap distribution.

The bootstrap procedure is repeated using the first 2 through 10 principal
components.

The PCA loadings and protein selection are held fixed during bootstrap
resampling.

### Outputs

Results are written to:

`output/transitional_state/`

Outputs include:

- `PC_projection.csv`
- Bootstrap projection distribution plots
- `PCA_transitional_state.png`

The projection analysis quantifies relative positions within the selected
proteomic feature space.

## Ingenuity Pathway Analysis (IPA)

Upstream regulator analyses, including the predicted 5-fluorouracil inhibition
signature, were performed using QIAGEN Ingenuity Pathway Analysis (IPA).

The input files used for IPA were generated by the limma differential protein
abundance workflow (`scripts/limmas.R`) and are provided in:

`input/ipa_input_files/`

The directory contains the differential abundance results for all six pairwise
comparisons and four one-versus-rest comparisons between the GATA6/K17-defined
cell populations.

As described in the manuscript Methods, the following columns were imported
into IPA:

- `Gene.Symbol`
- `logFC`
- `P.Value`

Proteins meeting a nominal significance threshold of p < 0.05 were considered
significant for downstream IPA analyses.

The original differential abundance results can be regenerated using the
scripts and protein abundance data provided in this repository. The archived
IPA input files represent the outputs used for the manuscript's pathway
analyses.

QIAGEN IPA is proprietary software. This repository provides the input datasets
used for IPA but does not reproduce the proprietary IPA analysis environment.

## Reproducibility

This repository provides the R analysis scripts, protein abundance matrix,
sample metadata, MSigDB reference gene sets, and limma-derived IPA input files
associated with the proteomic analyses described in the manuscript.

The IPA input files are archived in `input/ipa_input_files/`, allowing the
reported pathway analyses to be performed using the same differential abundance
results without first rerunning the limma script.

The analysis workflow includes:

1. Protein matrix and sample metadata preparation
2. limma differential protein abundance analysis
3. Unsupervised proteomic analysis
4. Principal component centroid projection
5. Bootstrap confidence interval estimation
6. Generation of differential abundance inputs for IPA

Software environment information is provided in:

`sessionInfo.txt`

The repository is intended to be archived through a tagged GitHub release and
Zenodo.
